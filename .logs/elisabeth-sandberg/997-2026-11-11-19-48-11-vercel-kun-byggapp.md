# Vercel: kun ByggAPP

## 2026-11-11 kl. 19:48 — Elisabeth Sandberg

### Oppgave
Endre Vercel-oppsettet slik at det bare gjelder ByggAPP, og legge oppsettet i rotmappen til ByggAPP i stedet for i repo-roten.

### Plan
- Flytte `vercel.json` fra repo-roten til `ByggAPP/vercel.json`.
- Erstatte `services`/`rewrites`-oppsettet (fra [vercel-deploy](999-2026-11-03-20-12-00-vercel-deploy.md) og [vercel-kun-ai-byggplant](998-2026-11-05-vercel-kun-ai-byggplant.md)) med et vanlig Vite-oppsett for én app.
- Sette Root Directory til `ByggAPP` i Vercel-prosjektet.

### Resultat
- `vercel.json` er flyttet (`git mv`) til `ByggAPP/vercel.json` og inneholder nå bare `framework: vite`, `npm ci`, `npm run build` og `outputDirectory: dist`. Ingen tjenester eller omskrivinger; appen ligger på rotadressen (`/`).
- `vite.config.ts` bruker `base: '/'` når `BASE_PATH` ikke er satt, så ingen kodeendring trengs.
- `npm run build` i `ByggAPP/` går gjennom (tsc + vite).
- Committet som `6e46402` og pushet til `main` sammen med loggcommitene.
- Punktene om AI_BYGGplant på Vercel i `issues.md` er markert som utgått, siden AI_BYGGplant ikke lenger publiseres der.

### Åpne punkter
- Sette Root Directory til `ByggAPP` i Vercel (Settings → Build and Deployment → Root Directory). Uten dette finner ikke Vercel `vercel.json` og `package.json`, og bygget feiler.
- Sjekke etter neste deploy at https://g115-endregaard-haaseth-sandberg-en.vercel.app/ viser ByggAPP.
