# AI_BYGGplant v0.1

## 2026-10-29 kl. 21:45 — Trond Engelstad

### Oppgave
Create a new folder `AI_BYGGplant/` with an app that visualises and structures a building process. The input is AI-generated without rules and is shown in the ByggAPP style. It opens with «Hei, hva skal bygges?», then the AI asks questions, narrow first (terrain, size, floors, doors, windows, a gate for a garage) and broader later, and then makes a budget and a Gantt chart. The dialog is always open for changes, and the app has tabs. Start with a draft, follow BMAD, push to Git and use the same G115 rules as ByggAPP.

### Plan
- Same stack and look as ByggAPP (Vite + TypeScript, Fluent glass, icons copied from ByggAPP).
- Claude (claude-opus-5-5) behind a Vite dev-server route `/api/turn`, so the API key stays on the server. Structured output against a strict JSON schema: reply, phase, questions with answer chips, and the whole project.
- The dialog on the left, always open; tabs Oversikt, Bygget, Budsjett, Fremdrift on the right.
- BMAD spec in `AI_BYGGplant/.docs/implementation-artifacts/`; G115_Changelog.md and G115_Dilemmas.md in `AI_BYGGplant/`.

### Resultat
- `AI_BYGGplant/`: `server/prompt.ts` (system prompt and schema), `server/claude.ts` (route, errors, refusal fallback), `src/session.ts`, `src/ui/building.ts` (four elevations and a plan), `src/ui/gantt.ts`, `src/ui/tabs.ts`, `src/main.ts`, `src/styles.css`.
- `npm test`: 9 passed. `npm run build`: OK. The dev server serves the page and the icons, and `/api/turn` answers 503 with a Norwegian hint when the key is missing.
- README (a new section and the folder list), the spec, the changelog and the dilemmas.
