# G115 Dilemmas

A record of the choices the AI (Claude Code) put to the group while building the simulator, and the group's answers. It shows which decisions were made by people and which were proposed by the AI, so the way from plan to code can be traced.

- One file per simulator version: [v0.1](v0.1.md), [v0.2](v0.2.md).
- Each entry has the AI's prompt (a summary of the question and its options) and the group's reply, word for word.
- New entries are added every time the AI asks the group to decide something, and they are pushed together with the change they belong to.
- Questions that are still open are listed at the end of the newest file.
