# Arkiv

Det som *Fra tomt til tak* har erstattet. Det er tatt vare på fordi det har ideer, data og kode gruppen bygger videre på, men det er ikke gjeldende. Prosjektet ligger i `FraTomtTilTak/`.

Ikke rediger filene her. Hentes en idé herfra, skriv den inn i de gjeldende dokumentene og si hvor den kommer fra.

| Mappe | Hva det er |
|---|---|
| `planning-artifacts/briefs/brief-G115-2026-10-29/` | Forrige product brief (Regjeringskvartalet Light), som instruktørens tilbakemelding på briefen gjelder |
| `planning-artifacts/prds/prd-G115-endregaard-haaseth-sandberg-2026-11-03/` | PRD for ByggAPP v0.5 |
| `planning-artifacts/prds/prd-G115-endregaard-haaseth-sandberg-2026-10-29/` | Påbegynt PRD som aldri ble fullført |
| `planning-artifacts/prds/prd-AI_BYGGplant-2026-11-05/` | PRD for AI_BYGGplant |
| `AI_BYGGplant/` | Appen der KI planlegger et byggeprosjekt i dialog (v0.5). Serverkoden kopieres inn i story 3.7 (FR-17). Kjøres med `npm install` og `npm run dev` i mappen. |
| `AI_BYGGplant-agenter/` | Agentene Ingrid, Jonas og Mats for AI_BYGGplant. Flytt dem tilbake til `.claude/skills/` hvis de skal brukes igjen. |
